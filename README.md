# Data Job Market Intelligence & Skills Analysis

## 📌 Project Overview

Analyzed 3,500 data-related job postings to identify patterns in job titles, required skills, seniority levels, locations, remote work, company sizes, and advertised salaries.

The project uses Excel and Power BI to clean, analyze, and visualize job-market data through an interactive dashboard.

## 🎯 Objective

To understand hiring patterns and commonly required skills in data-related job postings and present the findings through an interactive dashboard.

## 📊 Dataset

- Total Job Postings: 3,500
- Date Range: January 2023 – September 2025
- Source: Datanemics – Data Job Postings
- Format: CSV

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power Query
- PivotTables
- Power BI

## 🔄 Data Preparation

- Cleaned the job-posting dataset using Excel and Power Query
- Handled missing salary values
- Created an average salary field using minimum and maximum salary
- Split the skills column to analyze individual skills
- Used PivotTables to explore job titles, seniority, remote work, and other attributes

## 📈 Dashboard

The Power BI dashboard includes:

- Total Job Postings
- Average Advertised Salary
- Remote Job Postings
- Number of Cities
- Job Demand by Title
- Average Salary by Job Title
- Seniority Distribution
- Remote Work Distribution
- Top Skills by Number of Postings
- Interactive filters for Country, Seniority, and Remote Work

## 🔍 Key Insights

- The dataset contains 3,500 job postings.
- 1,061 postings are listed as fully remote.
- Salary information is available for a subset of the postings.
- SQL and Python appear prominently among the required skills.
- Job postings vary across titles, seniority levels, locations, and company sizes.
